# Literature Digest RSS

Daily curated literature digest — **one RSS item per day**.

## Subscribe

```
https://yorks0n.github.io/literature-digest-rss/feed.xml
```

Add that URL in any RSS reader (Feedly, NetNewsWire, Reeder, Inoreader, …).

## Site

- Landing: https://yorks0n.github.io/literature-digest-rss/
- Feed: https://yorks0n.github.io/literature-digest-rss/feed.xml

Published from local digests via `zotwatch-workspace/scripts/publish_digest_rss.py`.
Independent of `Yorks0n/zotwatch-feed`.
